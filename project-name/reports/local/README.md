# Local Agent Output

This directory contains developer-specific output that is not part of the project's shared history.

Examples include:

- copy-ready `.txt` files produced by `m-text`
- personal HTML or Markdown summaries
- temporary explanations, lists, and handoff notes

Generated files in this directory are ignored by Git. Do not place secrets, credentials, sensitive production data, or required project documentation here.

Default naming:

```text
reports/local/<topic>.txt
reports/local/<topic>.md
reports/local/<topic>.html
```
