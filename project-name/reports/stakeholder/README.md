# Stakeholder Reports

This directory contains non-technical HTML summaries of completed work. They are tracked project deliverables in Shared mode and remain local in local-only mode.

Use:

```text
reports/stakeholder/<plan-file-stem>-summary.html
```

Start from `docs/templates/stakeholder-summary-template.html` and follow `.github/agent-modules/plan-executor/stakeholder-summary.md`.
