# Reports

This directory is the standard home for human-readable artifacts generated by agents.

## Structure

```text
reports/
├── execution/
├── stakeholder/
└── local/
```

- `execution/` contains technical execution reports tied to plans or substantial direct work.
- `stakeholder/` contains plain-language HTML summaries for product owners, project managers, and other non-technical stakeholders.
- `local/` contains developer-specific, copy-ready, or disposable output. Its generated contents are ignored by Git.

Do not write generated reports to the repository root. A user-specified path may override these defaults when the destination is safe and appropriate.

In Shared mode, execution and stakeholder reports are tracked project deliverables. In local-only mode, the workflow state and clone-local exclusions keep the template-added report tree local. Keep reports evidence-based, free of secrets, and linked to the relevant demand, plan, or implementation when useful.
